# SasetEM

Instaladores y actualizaciones de **SasetEM**, simulador de radiofrecuencia y planificación de redes móviles.

## Descargar

### [⬇ Descargar el instalador de SasetEM (Windows)](https://github.com/jefrira/SasetEM-releases/releases/latest/download/SasetEMApp-win-Setup.exe)

Siempre descarga la última versión. Las versiones anteriores y sus notas están en [Releases](https://github.com/jefrira/SasetEM-releases/releases).

## Instalar

1. Ejecuta `SasetEMApp-win-Setup.exe`. No pide permisos de administrador.
   Si Windows muestra "Windows protegió su PC", pulsa **Más información → Ejecutar de todas formas**.
2. SasetEM se abre al terminar y crea accesos directos en el escritorio y en el menú Inicio.
3. La primera vez pide la **clave de licencia**. Solicítala a tu docente o administrador.

## Requisitos

- Windows 10 u 11 de 64 bits.
- Conexión a internet para validar la licencia.

## Actualizaciones

SasetEM busca versiones nuevas al abrirse y ofrece **Actualizar ahora**. Solo descarga lo que cambió.
